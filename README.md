# Warm Anti-Halation Theme Suite

Zestaw motywów dla VS Code zoptymalizowany pod kątem astygmatyzmu i redukcji zmęczenia oczu.

## Cechy
- **Brak światła niebieskiego**: Kolory zaimplementowane na falach 550–620 nm (oliwka, bursztyn, miedź).
- **Redukcja halacji (poświaty)**: Tło `#363634` (wariant ciemny) oraz `#f4efe6` (wariant jasny) wymuszają optymalne zwężenie źrenicy.
- **Zoptymalizowany kontrast Webera**: Zachowany w granicach 6.5:1 – 7.5:1.

## Warianty
1. **Warm Anti-Halation Dark**
2. **Warm Anti-Halation Light**
